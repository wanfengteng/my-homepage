08 — About me

关于我

在前端交互、后端接口和创意项目之间摸索的学习者。

大家好，我是谭博文。2023 年进入山东职业学院读软件技术，2026 年通过专升本考试来到山东女子学院读数字媒体技术。

掌握 Web 开发技术栈，熟悉 HTML、Vue、MySQL 与 Spring Boot，也了解 Java、Python、C。最近在研究怎么让 Agent 自己出设计思路、拆任务、调工具、验收，把一句要求真正做完。

摄影是我另一个兴趣。按下快门前我会先找引导线、找对称、找前景的框——这些训练也反过来影响了我做页面时的排版直觉：留白、层级、视觉动线，本质上是同一件事。

对 Web 开发有兴趣的朋友，欢迎留言指导交流。最近对嵌入式与具身智能方向比较感兴趣，方向一致的同学也欢迎一起交流进步。联系方式在首页与留言页。
